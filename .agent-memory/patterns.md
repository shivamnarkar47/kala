# Patterns

## 2026-08-23 — slash-command palette (internal/tui/slash.go)
One metadata table (`slashCommands`: name/args/desc) feeds the popup, tab-completion, AND /help — never add a parallel list. Palette rules: name-prefix matches first, description substring only at ≥3 chars (else 1-char queries flood); popup is OVERLAID on the viewport's lower rows via `overlayBottom` (must never push layout); enter executes EXACT known commands, completes partials to the cursor entry (+space when args exist), unknown typos get `slashNearest` did-you-mean. GOTCHA: `t.TempDir()` inside a closure regenerates per CALL — pin the path once before wrapping it in ccCachePath-style seams.

## 2026-08-23 — the Kurukshetra skin (internal/tui/theme.go)
All Mahabharata theming lives in `internal/tui/theme.go` + a few render sites in tui.go: palette vars (saffron 214 / gold 220 / peacock 69 / ember 203 / ivory 223 / blood 196), `pandavaIdentities` map (sigil+epithet+color per Pandava; `identityFor()` falls back to saffron `✶ kshatriya` for custom agents like Karna), chariot hero art, Gita 2.47 verse, chakra spinner frames. Assistant answer blocks carry the active Pandava's name (`▌ Bhima`) in their color; fallback voice is `▌ kaal`. Modals retitled Itihasa/Astras/Sabha/Diksha. GOTCHA: ~15 strings are test-pinned verbatim (`KURUKSHETRA`, `field of dharma`, `ask a task`, `kaal 0.3`, `Workspace`, `KAAL`, `step %d/%d`, `tok/s`, `ready`, `Yudhishthira`, `⚙ read`, `turn cancelled`, `/resume` help, ask-modal numbering, `per M`, `termaid`) — restyle around them, never through them. Status-bar badge must stay compact (no epithet — pinned by TestStatusBarBadgeKeepsSegments). Art runes must stay single-width or wheels misalign.
